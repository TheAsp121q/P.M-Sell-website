P.M — Selling Website
P.M is a selling website designed for offering and selling services online.

The project includes a working email-receiving system powered by EmailJS, allowing submitted messages and inquiries to be received through the configured email service.

Features
Service-selling platform
Service presentation and listing
Working email/contact functionality using EmailJS
Frontend-focused selling experience
Simple and straightforward design
Important Notes
The node_modules folder is not included in this repository.
Run the appropriate package manager installation command before starting the project.
Some configuration values may need to be set up locally depending on the environment.
Status
The project is functional, particularly the email-receiving functionality, but it may still require additional polishing and improvements. As i use for my services!
